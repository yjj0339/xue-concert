## 这是什么

一场完全运行在浏览器里的虚拟演唱会：**128 BPM 节拍时钟**驱动 **2 分 15 秒、10 个章节、自动循环**的导演秀；观众可随时切入**自由机位**（演出不暂停），自己触发特效、摆灯牌、放飞无人机编队——演出永不停机。

- **场馆**：Blender 手工建模的鸟巢（钢结构编织网格 + 中央开口 + 三层看台 + 主舞台 + 四座兽塔 + 巨型曲面主 LED 墙），Draco 压缩 GLB；双份策略——`model.glb` 供 http(s)，base64 内嵌 `js/model-data.js` 供 **双击 index.html（file://）直接看**。
- **20 组大型特效**（场内 11 + 场外 9）全部可单独触发，金色「特效巡礼」按钮按序自动巡演；经典特效（烟花/火焰/激光/频闪/CO₂/彩带/火花瀑布/人浪）随时可放。
- **两个编辑器**：灯牌（8 块，小地图点击放置/拖动，霓虹/灯泡/LED 三样式 × 四动态）与无人机编队（3 队 × 2200 架，文字 + 13 种图案，轮廓+均匀填充），localStorage 保存，URL 参数优先。
- **外景世界**：龙形水系（音乐喷泉 + 倒影）、雨后湿地广场、奥林匹克公园、水立方、玲珑塔、奥林匹克塔、北京城市天际线、车流、探照灯。
- **HDR 后处理**：大气 → 景深 → 运动模糊 → 泛光 → 变形拉丝 → ACES 色调映射；四档画质（0.55–3.6 MP）+ 自适应降档，**档位切换不着色器重编译**。
- **程序化音频**：WebAudio 合成鼓组/贝斯/Pad/人群欢呼，128 BPM 与灯光同钟；**烟花爆点按 343 m/s 声速距离延迟到达**。

## 快速开始

| 方式 | 说明 |
| :--- | :-- |
| 双击 `index.html` | 内嵌 base64 模型兜底，file:// 完整可看（需联网加载 three.js） |
| 本地服务器 | `node tools/server.js` → <http://127.0.0.1:8137/>（读 GLB 更快） |
| 线上 | GitHub Pages，见顶部链接 |

## 操作

| 按键 | 作用 |
| :-- | :-- |
| 左键拖动 / 滚轮 / 右键拖动 | 自由模式旋转 / 缩放 / 平移 |
| `W A S D` / `Q` `E` / `Shift` | 飞行 / 降升 / 加速 |
| `1`–`9`、`0` | 前 10 机位（共 16 个在左侧「机位」面板） |
| `Space` | 演出 → 自由模式（自由模式锁定，仅底部「演出」按钮可返回） |
| `M` / `H` / `F` | 声音 / 隐藏界面 / 全屏 |
| `←` / `→` / `K` | 上一章 / 下一章 / 暂停 |
| 点击时间轴 | 跳转章节 |

## URL 参数（40+，完整表见 index.html 头部注释）

```
?mode=free&view=6&quality=ultra      自由模式 + 7 号机位 + 极致画质
?chapter=9&speed=0.5                 终章慢放
?sign=鸟巢见&signColor=gold&ticker=true   湖边金色灯牌 + 屋顶跑马灯
?drone=薛之谦&droneShape=text&droneColor=cyan  无人机文字编队
?stats=1                             帧率/分辨率/draw call/灯光数/GPU
```

## 工程结构

```
xue-Concert/
├ index.html          页面结构 + KOB_CONFIG 参数说明大注释
├ css/show.css        界面样式（金黑演唱会视觉系统）
├ js/kob-params.js    40+ 参数解析（URL > data-* > 配置 > 默认）
├ js/kob-glsl.js      全部着色器（LED/光束/激光/粒子/人群/无人机/后处理…）
├ js/kob-show.js      10 章节、导演相机路径、cue 表、烟花时刻表、16 机位
├ js/kob-fx.js        特效系统：粒子池/光束/激光/烟花/火焰/人群/无人机/灯牌…
├ js/kob-sfx.js       20 组大型特效目录 + 特效巡礼
├ js/kob-world.js     奥林匹克公园外景（龙湖喷泉/水立方/城市天际线/车流…）
├ js/kob-post.js      HDR 后处理链（DOF/运动模糊/泛光/拉丝/ACES）
├ js/kob-ui.js        顶栏/底栏/时间轴/章节卡/自动隐藏
├ js/kob-deck.js      左侧控制台：机位/特效/灯牌/无人机编辑器（小地图）
├ js/audio.js         WebAudio 程序化配乐（烟花声速延迟）
├ js/kob-main.js      启动：CDN 探测(importmap) → 模型 → 导演相机 → __viewer
├ js/model-data.js    内嵌场馆模型（base64 glTF-Binary + Draco）
├ model.glb           场馆模型（Blender 建模，几何冻结）
└ tools/              Blender 建模脚本 / 静态服务器 / 冒烟测试
```

开发者接口 `window.__viewer`：`flyTo(i)` / `setMode()` / `seek()` / `renderAt(t)`（出 JPEG 帧）/ `bench(t, n)` / `VIEWS` / `stats()`。

three.js r160 从 CDN 动态加载（jsDelivr → unpkg → npmmirror 自动探测，`?cdn=` 可强制）；断网时启动屏会提示镜像参数。
